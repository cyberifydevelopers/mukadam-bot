How LangGraph handled them

Each email runs through a three-step LangGraph flow. Only emails with a bank document reach the WhatsApp step.

  1. Read documents opens each attachment. When an email has no attachment, the bot reads its body instead.
  2. Analyze documents makes one LLM call per document. It judges from the letterhead whether a bank wrote it, names the bank and pulls out the reference, date, amount and items.
  3. Notify sends one WhatsApp YES / NO message per selected document. A YES saves the row to that bank's tab in the sheet.
